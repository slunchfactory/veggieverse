## 업무 흐름 (Workflow)

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  슬런치 작업 중  │ → │ 슬런치 검수 완료 │ → │  개발자 확인 중  │ → │ 개발자 검수 완료 │
│   (디자이너)    │    │  (턴 → 개발자)  │    │   (개발자)      │    │   (최종 승인)   │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```
