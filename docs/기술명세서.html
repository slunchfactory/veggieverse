02. 기능 정의서

공통 기능

No영역기능명기능 설명비고
1 공통_헤더 사이트 헤더를 통해 주요 페이지에 접근할 수 있다. 구성 요소
  • 왼쪽: 햄버거 메뉴 버튼 (NavigationDrawer 열기)
  • 중앙: VeggieVerse 로고 (홈 링크)
  • 오른쪽: 장바구니 아이콘 (뱃지 카운트), 사용자 프로필 아이콘
사용자 상태별 분기
  • 비로그인: 기본 프로필 아이콘 → 클릭 시 로그인 모달
  • 로그인: 스피릿 아바타 이미지 표시
동작
  • Sticky 포지셔닝 (top: 0, z-index: 50)
  • 프로모 배너 유무에 따라 높이 가변 (64px / 96px)
2 공통_프로모배너 상단 프로모션 배너를 표시/닫기할 수 있다. 기능
  • 페이지 최상단에 프로모 메시지 표시
  • X 버튼으로 닫기 가능 (세션 내 유지)
  • 닫기 시 헤더 높이 자동 조정
3 공통_네비게이션드로어 햄버거 메뉴에서 전체 사이트 메뉴를 탐색할 수 있다. 기능
  • 왼쪽에서 슬라이드인 되는 풀스크린 드로어
  • 주요 메뉴: 스토어, 레시피, 구독, 이벤트, 뉴스레터, 소개
  • 마이페이지 바로가기 포함
  • 배경 오버레이 클릭 시 닫힘
4 공통_푸터 사이트 하단에 기업 정보 및 링크를 제공한다. 구성 (반응형) 홈 페이지에서는 미표시
  • ABOUT: 브랜드 스토리, 매장, B2B 링크
  • NEWSLETTER: 뉴스레터 안내
  • CONTACT: 이메일 주소
  • SOCIAL: Instagram, YouTube, LinkedIn 외부 링크
  • BANK: 계좌 정보
  • CS: 고객센터 정보
  • 모바일 2열 / 데스크톱 5열 반응형 레이아웃
5 공통_AI챗봇 AI 챗봇을 통해 대화형으로 추천/정보를 받을 수 있다. ChatTrigger
  • 화면 우하단 고정 플로팅 버튼
ChatPanel
  • 데스크톱: 360×600px 패널
  • 모바일: 80vh 바텀시트
3개 탭
  • Chat: 대화 탭 + 빠른 질문 버튼 (점심 추천, 주간 식단, 장보기 리스트, 저염·고단백)
  • My Spirit: 프로필 정보 (식단 유형, 좋아하는/싫어하는 것, 알러지)
  • Bookmarks: 저장된 레시피 그리드 (2열, 12개 목업)
6 공통_스크롤투탑 페이지 최상단으로 스크롤하는 버튼을 제공한다.
  • ScrollToTop 컴포넌트
  • 라우트 변경 시 자동 스크롤 투 탑
7 공통_로그인 사용자 로그인/로그아웃 기능을 제공한다. 로그인 모달
  • 프로필 아이콘 클릭 시 LoginModal 표시
  • 로그인 시 UserContext에 사용자 정보 저장
로그아웃
  • LogoutConfirmModal로 확인 후 처리, localStorage 초기화
8 공통_에러처리 페이지 렌더링 에러를 우아하게 처리한다.
  • ErrorBoundary 컴포넌트로 레시피 상세 등 감싸기
  • 에러 발생 시 폴백 UI 표시

스피릿 찾기

No영역기능명기능 설명비고
10 스피릿_인트로 사용자는 플로팅 채소 중 3개를 선택하여 테스트를 시작할 수 있다. 채소 선택 인터랙션 body 스크롤 비활성화
  • 풀스크린 플로팅 채소 영역 (물리 시뮬레이션)
  • 1:1 비율 이미지, 호버 시 이름 라벨 노출
  • 채소 클릭 시 하단 선택바에 추가 (최대 3개)
하단 선택바
  • 고정 하단 바에 선택된 채소 3개 미리보기 표시
  • 3개 선택 완료 시 "시작하기" 버튼 활성화
  • Skip 버튼으로 선택 없이 질문 단계로 직행 가능
11 스피릿_질문 사용자는 7단계 질문에 답하여 비건 스피릿 유형을 진단받을 수 있다. 질문 구성 (7단계) /spirit/question/:stepId
  1. 식단 유형: The Feast / The Garden / The Ocean / The Dawn / The Balance
  2. 추가 옵션: 글루텐프리 / 유당불내증 / 없음
  3. 요리 무드: 전통 / 퓨전 / 심플 / 고메
  4. 우선순위: 영양 / 맛 / 편의 / 새로움
  5. 식사 의미: 가족 / 건강 / 간편 / 경험
  6. 식사 패턴: 규칙적 / 유연 / 계획적 / 즉흥적
  7. 채식 이유 (조건부): 건강 / 환경 / 동물 / 호기심
UI
  • 타로 카드 스타일 옵션 표시
  • 진행률 인디케이터
  • URL 기반 단계 네비게이션
  • localStorage에 답변 중간 저장
12 스피릿_결과 사용자는 16개 비건 스피릿 유형 중 결과를 확인하고 공유할 수 있다. 16개 스피릿 유형 (MBTI 기반) /spirit/result
  • Bloomist (ENFP), Mindgrower (INFP), Quiet Root (INFJ), Lightgiver (ENFJ)
  • Forger (ENTJ), Groundtype (ESTJ), Planter (ISTJ), Strategreen (INTJ)
  • Floret (ISFP), Joybean (ESFP), Careleaf (ESFJ), Nurturer (ISFJ)
  • Thinkroot (INTP), Sparknut (ENTP), Craftbean (ISTP), Wildgrain (ESTP)
결과 화면
  • 스피릿 이름, 이모지, 컬러, 설명 표시
  • 스피릿 기반 추천 레시피 캐러셀
프로필 저장
  • localStorage veggieverse-profile 키에 저장
  • 저장: profileImage, veganType, savedAt
  • 헤더에 스피릿 아바타 즉시 반영
공유 기능
  • 결과 카드 소셜 공유 모달
