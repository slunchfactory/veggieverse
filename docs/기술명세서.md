## 01. IA (Information Architecture) / User Flow

### 사이트맵

```
VeggieVerse
│
├── 홈 (/)
│   ├── 플로팅 채소 인터랙션
│   ├── 무드 슬라이더
```

### User Flow

```
[첫 방문] → 홈(플로팅 채소) → "나의 스피릿 찾기" CTA 클릭
    ↓
[스피릿 찾기] → 채소 3개 선택 → 7단계 질문 → 16개 유형 중 결과
    ↓
[결과 저장] → localStorage에 프로필 저장 → 헤더에 스피릿 아바타 표시
    ↓
[콘텐츠 탐색]
    ├── 레시피 → 카테고리 탐색 → 상세 보기 → 북마크/리뷰 작성
    ├── 스토어 → 필터/정렬 → 상품 상세 → 장바구니 → 구매 (Coming Soon)
    ├── 구독 → 플랜 선택 → 메뉴 커스텀 → 결제 (Coming Soon)
    ├── 뉴스레터 → 아티클 읽기
    └── 이벤트 → 이벤트 참여
    ↓
[마이페이지] → 주문 관리 / 즐겨찾기 / 위시리스트 / 리뷰 / 프로필
```
